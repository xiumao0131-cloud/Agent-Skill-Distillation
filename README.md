# Agent Skill Distillation

A research project exploring how to distill reusable skills from human-agent workflows and transform expert experience into structured, executable capabilities for AI agents.

## Project Goal

This project explores how to extract practical workflows, rules, and evaluation criteria from real-world human-agent interactions, and convert them into reusable AI agent skills.

## Current Experiment

### Academic Revision Skill

The first experiment focuses on extracting academic document formatting and revision capabilities from WorkBuddy execution traces.

Goal:

- Reduce agent response uncertainty
- Improve task completion consistency
- Build reusable skill modules
