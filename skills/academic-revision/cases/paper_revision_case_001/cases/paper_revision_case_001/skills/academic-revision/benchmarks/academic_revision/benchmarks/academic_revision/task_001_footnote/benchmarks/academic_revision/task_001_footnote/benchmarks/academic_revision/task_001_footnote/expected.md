# Expected Result


## Required Actions


The agent should:


1. Identify that manually typed footnote text does not equal a real Word footnote.


2. Explain that document structure needs verification.


3. Convert or recommend conversion to real Word footnotes if required.


4. Avoid creating unsupported citation information.


5. Provide a modification report.



## Failure Examples


The following behaviors are considered failures:


- Only changing the appearance of footnote numbers

- Assuming typed notes are valid footnotes

- Creating fake references

- Rewriting academic content
