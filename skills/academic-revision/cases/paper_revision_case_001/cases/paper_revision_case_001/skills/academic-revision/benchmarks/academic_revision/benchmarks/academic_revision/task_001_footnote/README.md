# Task 001: Footnote Validation


## Objective

Test whether an agent can distinguish between:

- real Word footnotes
- manually typed footnote-like text


## Skill Capability Tested

- document structure awareness
- citation validation
- requirement interpretation


## Scenario

A student submits an academic assignment.

The document appears to contain footnotes.

However, some footnotes may only be manually typed in the document body.


## Expected Agent Behavior

The agent should:

1. Inspect the document structure

2. Identify whether footnotes are real Word objects

3. Report problems clearly

4. Avoid inventing citation information
